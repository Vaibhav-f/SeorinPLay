📖 About The Project

SeorinPlay is a modern movie discovery and streaming platform that allows users to explore trending, popular, and top-rated movies through a clean and responsive user interface.

The application fetches real-time movie data from the TMDB API and provides a seamless user experience across mobile, tablet, and desktop devices.

This project demonstrates frontend development skills including:

React Component Architecture
API Integration
State Management
Responsive Design
Modern UI/UX Design
Routing & Navigation
Performance Optimization
